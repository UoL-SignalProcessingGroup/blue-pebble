# Tutorials

The tutorials provide guided, end-to-end workflows for building passive sonar scenarios with Nereus and Stone Soup concepts.

- [Single-Target Tutorial](single_target_tutorial.ipynb) introduces the basic simulation flow for a single contact.
- [Multi-Target Tutorial](multi_target_tutorial.ipynb) extends the workflow to a more complex scenario with multiple contacts.
