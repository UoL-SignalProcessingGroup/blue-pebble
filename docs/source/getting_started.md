# Getting Started

For a first end-to-end walkthrough, begin with the [Single-Target Tutorial](../tutorials/single_target_tutorial.ipynb). It introduces a compact passive sonar scenario and the main simulation concepts used throughout the project.

After that, these example notebooks provide useful next steps:

- [Modelling Acoustic Sources](../examples/modelling_acoustic_sources.py) for an overview of some existing acoustic source models.
- [Comparing Simulators](../examples/comparing_simulators.py) for comparing simulator backends.
- [Designing Narrowband Beamformers](../examples/designing_narrowband_beamformers.py) for beamforming trade-offs.

If you want to inspect the underlying classes and modules after working through the notebooks, continue to the [API Reference](api/index.md).
